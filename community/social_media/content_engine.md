# Narayan Labs: Content Engine

## Overview
The Content Engine is a repeatable, scalable system for generating high-impact assets that drive engagement and contributor growth. It relies on standardizing formats so the core team can produce content efficiently without distracting from research and engineering.

---

## The 5 Core Content Formats

### 1. Research Threads (X/LinkedIn)
Deep-dives into specific AI/ML topics relevant to India.
- **Structure:**
  1. **The Hook:** A counter-intuitive statement or bold claim about Indian AI.
  2. **The Context:** Why the current global approach doesn't work for Bharat.
  3. **The Deep Dive:** Technical explanation (architecture, tokenization, data).
  4. **The Visual:** An architecture diagram or data plot.
  5. **The CTA:** "Read our full manifesto on GitHub" / "Join the research discussion on Discord."
- **Frequency:** 1x / Week

### 2. Dataset Releases
High-visibility announcements of newly curated, cleaned, and open-sourced data.
- **Structure:**
  1. **The Announcement:** "We are open-sourcing [Dataset Name]: The largest [Type] dataset for [Language/Domain]."
  2. **The Problem Solved:** What models can now be trained using this data.
  3. **The Stats:** Size, tokens, quality filters applied.
  4. **The Examples:** 2-3 fascinating examples of the data itself.
  5. **The CTA:** Direct link to the Hugging Face repo & GitHub documentation.
- **Frequency:** 1-2x / Month

### 3. Open Research Problems (ORPs)
Crowdsourcing solutions to current technical bottlenecks.
- **Structure:**
  1. **The Bounty/Challenge:** "We need help solving [Specific Technical Problem]."
  2. **Current State:** "We tried X and Y, but it failed because of Z."
  3. **The Constraints:** Compute limits, latency requirements, etc.
  4. **The Reward:** "First merged PR gets a shoutout, Narayan Labs swag, and fellowship consideration."
  5. **The CTA:** Link to the specific GitHub Issue tagged `help wanted`.
- **Frequency:** Bi-weekly

### 4. Contributor Spotlight
Celebrating the community members who push the lab forward.
- **Structure:**
  1. **The Accolade:** "Huge shoutout to @username for merging PR #[number]."
  2. **The Impact:** "This PR improves our data pipeline speed by 40%."
  3. **The Profile:** Brief background on the contributor (student, professional).
  4. **The CTA:** "Want to build the future of Indian AI? Check our good-first-issues here: [Link]"
- **Frequency:** Weekly

### 5. Weekly Narayan Labs Progress Updates
Consistent, transparent communication about what the core team built this week.
- **Structure:**
  1. **TL;DR:** 3 bullet points of what shipped.
  2. **Code Merged:** Links to the 2-3 most important PRs.
  3. **Data Processed:** "We cleaned 50GB of Hindi text this week."
  4. **What's Next:** What the team is focusing on next week.
  5. **The CTA:** Link to the GitHub roadmap/project board.
- **Frequency:** Every Friday (Build-in-Public Friday)

---

## Content Generation Workflow
1. **Monday:** Capture technical notes from engineering syncs into a shared draft document.
2. **Wednesday:** Format raw notes into the 5 templates above.
3. **Friday:** Schedule threads and posts for the following week using scheduling tools.
