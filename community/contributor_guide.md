# Contributor Guide

Whether you are a seasoned NLP researcher or a first-time open-source contributor, your help is essential to our mission.

## Getting Started
1. **Join the Conversation**: Introduce yourself in our GitHub Discussions under the "Introductions" category.
2. **Find an Issue**: Go to our Issues tab and look for the label `good first issue` or `help wanted`.

## Contribution Pathways

### 1. Code (Models & Infrastructure)
Help us optimize our training pipelines (Axolotl/Unsloth integrations) or improve our serving architecture.
**Prerequisites**: Python, PyTorch, Docker.

### 2. Data Curation
Help us source, clean, and verify open-source datasets in your native language.
**Prerequisites**: Native language fluency, basic scripting for scraping/cleaning.

### 3. Translation & Prompt Engineering
Write rigorous prompt/response pairs in Indic languages to help instruction-tune our base models.

### 4. Testing & Evaluation
Run our beta models locally using `llama.cpp` or via our testing endpoints and report factual errors, hallucinations, or toxic outputs.

## Development Workflow
- Fork the repository.
- Create a feature branch: `git checkout -b feature/your-feature-name`.
- Write your code/documentation.
- Commit using Conventional Commits guidelines (e.g., `feat: add Tamil data scraper`).
- Push and open a Pull Request against `main`.

Thank you for helping us build AI for Bharat!
